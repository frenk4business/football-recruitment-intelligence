## Capability and stability assessment

For event sources, match lists/file presence establish source availability only; robust minutes, roles, feature semantics and retrieval evidence determine recruitment. Neither source has a validated men's cross-league translation model here. Tracking, metadata and video sources never inherit performance/translation capabilities. All new input files receive URL, revision, size and checksum records; immutable source revisions remain usable offline. GitHub datasets are mutable on their default branches, Figshare articles are versioned, video/gated sources have additional availability restrictions. No unpinned automated source discovery feeds production.

The machine-readable `config/v12-source-registry.json` records event/tracking/lineup/DOB/club/position availability, recommended uses and exact measured country/competition/season/file counts. Unknown or unmeasured counts stay null, not invented zeroes. Catalogue-derived player counts are not unique cross-provider persons.

## Fresh European coverage search

Searches covered legitimate open event sources for Eredivisie, Primeira Liga, Belgium, Scotland, Austria, Switzerland, Denmark, Norway, Sweden and Turkey, alongside academic synchronized-event datasets. The official sources above support broader fixtures/club discovery, but this audit has not established a reusable substantial named-player event feed for those additional leagues. Eredivisie research papers describe access to private tracking/event data; publication of an article is not publication of its underlying licensed dataset. Keep these leagues metadata-only unless a future source passes the same audit. No FBref/FotMob/Sofascore/WhoScored/Transfermarkt/Understat scraping is introduced.

## Initial inclusion decisions

Retain all v1.1 sources and outputs. Reuse cached pinned Big Five raw/Parquet files for richer Wyscout extraction. Expand StatsBomb men's separate domestic/European/tournament scopes wherever usable participation survives validation, including explicitly partial Bundesliga and near-complete Ligue 1. Do not blend tournament appearances into domestic seasons. Ingest official OpenFootball Europe/European club/player files and European football.json fixtures into an isolated metadata layer. Add SkillCorner specialist aggregate records separately, with no inferred person matches. Exact processed, excluded and published counts are outputs of the subsequent build, not assumptions in this audit.

Additional discovery checks on 2026-10-02 covered all ten requested prospective leagues. The [Austrian event-detection paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11025972/) explicitly separates its reusable Metrica sample from commercial match data it cannot share. [OpenFootball’s official European catalogue](https://github.com/openfootball/europe/blob/master/README.md) supports fixtures, not a named-player event feed. Third-party indexes/API marketing did not establish an authoritative reusable event licence and were not ingested. This is a bounded search result, not a claim that no such dataset could exist.
