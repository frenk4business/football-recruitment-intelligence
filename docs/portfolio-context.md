The portfolio already demonstrates Next.js/React/TypeScript, manually defined English/Dutch content, static Render deployment, semantic content, research cases and source-aware reporting. Its README describes 15 project cases, Python/ML/computer vision research and existing product/dashboard work. Its editorial typography, restrained green palette, accurate evidence and accessible language routes provide useful continuity.

The added evidence here is in the engineering underneath the interface: heterogeneous adapters; stable identities; raw-to-canonical coordinate systems; explicit missingness; Parquet and SQL marts; input checksums and temporal provenance; publication-aware export; generated API contracts; fixture-based tests and CI. The website makes those decisions inspectable rather than claiming model capability. The local-first architecture also avoids another hosted dashboard/database dependency.
