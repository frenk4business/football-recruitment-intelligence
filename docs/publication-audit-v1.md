# Publication and source-rights audit v1

The pre-v1 inventory is 2,041 JSON artifacts / 36,277,787 bytes: Phase 1 aggregate sample (7), Player DNA (1,351), historical translation (663), recruitment (20). `config/public-artifacts.json` explicitly records source path, public path, schema, byte count and SHA-256. Build rejects unlisted files within publication directories, unknown output files, modified content, schema failures, symlinks and size overruns. `release-manifest.json` lists public artifact and final static file hashes, source revision/config hashes and scientific versions. Integrity manifests contain only relative public paths and hashes.

Published content is the existing derived research material, including the permitted, downsampled SkillCorner tracking sample. The build does not publish raw StatsBomb/Wyscout events or lineups, canonical Parquet/DuckDB, full posterior draws, source download caches, credentials, personal developer paths or sourcemaps. Synthetic raw-shaped unit fixtures stay in the source repository and are not copied into the static export. Names/football observations already in the open source data are not newly enriched with ages, fees, contracts or availability.

Source references were rechecked on 2026-10-01: [StatsBomb Open Data](https://github.com/hudl/open-data) and [user agreement](https://github.com/hudl/open-data/blob/master/LICENSE.pdf), [SkillCorner MIT](https://github.com/SkillCorner/opendata/blob/master/LICENSE), [Wyscout Figshare collection](https://figshare.com/collections/Soccer_match_event_dataset/4415000) and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Existing non-commercial/research constraints, logo and attribution remain; no additional right to redistribute provider raw feeds is inferred. Wyscout use is a separate metadata/identity feasibility audit, not a source of this model's event features. See [ATTRIBUTION](../ATTRIBUTION.md) for precise provenance and terms.

MIT applies to project code only. Provider data and trademarks retain separate rights. The site is independent and has no provider, league or club endorsement. This audit confirms the project's constrained publication policy; it is not a general legal clearance for commercial reuse.
