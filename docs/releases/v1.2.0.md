# v1.2.0 release record

Historical recruitment analysis now includes separately validated men’s Big Five Wyscout cohorts, alongside the existing WSL research workflow. The release adds broader discovery without treating metadata or small samples as recruitment evidence. [PR #23](https://github.com/frenk4business/football-recruitment-intelligence/pull/23) targets protected main from `feature/v1.2-max-data-expansion`.

## Coverage

- 3,739 event-performance player-season profiles; 3,527 provider identities; 71 provider competition-season scopes, 21 provider competitions / 18 competition families, 849 team-season/tournament scopes. 13,845,037 processed event observations from 4,863 matches.
- 98 newly enabled Wyscout club-seasons (20 England, 20 Spain, 20 Italy, 18 Germany, 20 France), 1,761 eligible profiles at ≥450 reliable nominal minutes, 24 provider-native features. Existing WSL contributes 12 clubs / 129 eligible profiles: 110 recruitment club-seasons total.
- 665 additional StatsBomb profiles from 27 usable new scopes; all 60 selected added scopes and all 80 catalogue scopes are audited. No new StatsBomb recruitment/similarity claims. Ligue 1 2015/16 is near-complete (377/380); Bundesliga 2015/16 is a 34/306 sample. Tournament observations remain separate.
- 3,736 OpenFootball source club entities, including 3,588 without a deterministic historical performance link; 25,885 isolated player metadata records, 473 source competition-season files / 138,166 fixture observations. These are source entities, not claimed unique real-world persons/clubs/matches. Duplicate fixture rows are withheld; source overlaps retained explicitly.
- 290 SkillCorner A-League 2024/25 specialist player-season records. No European recruitment breadth is attributed to them.

## Validation and limitations

The preregistered all-league role retrieval procedure, chance baselines, all four thresholds and weighting sensitivity are documented in the [evaluation](../v1.2-recruitment-expansion-evaluation.md). Recall@5 ranges 0.646–0.702 versus 0.042–0.048 chance; weighted league MRR 0.507–0.551 versus 0.044–0.050 chance. These are repeated-observation retrieval results, not transfer success. Broad provider roles remain DEF/MID/FWD. Club contexts are roster-profile medians/distributions, not isolated team tactical effects. Wider discovery uses observed native rates with target league-role scales; own-league percentiles are descriptive only. No league-strength or WSL translation is applied.

All 2,146 frozen scientific-lock files and all v1.1 public artifacts retain their original bytes. Prior tags and WSL URL semantics are preserved. OpenFootball names alone never join scientific player identities; deterministic metadata candidates stay separate. Source rights are in the [landscape](../v1.2-open-data-landscape.md) and machine registry. The product remains non-commercial under StatsBomb conditions; Wyscout CC BY 4.0, OpenFootball CC0 and SkillCorner MIT attribution remain distinct.

The expanded 142KB-gzip search index contains no profile vectors. All metadata, specialist records, details and additional recruitment leagues load on demand.
